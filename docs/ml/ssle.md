# Self-Supervised Learning

The model generates `its own labels directly from the raw data` structure itself.

No human labeling is involved at all.

<br/>

**Purpose**:
It hides parts of the data and challenges itself to predict the missing pieces.

**Example**:
This is the core framework used to pre-train modern Large Language Models (LLMs) like ChatGPT by predicting the next word in a sentence.

**Common Techniques**:
Masked Language Modeling (e.g., BERT) and Contrastive Learning.
