# Semi-Supervised Learning

A hybrid approach that combines a `small amount of labeled data` with a `large amount of unlabeled data`.

<br/>

**Purpose**:
This reduces the massive time and cost required for humans to manually label data.

**Example**:
Photo-hosting apps that cluster faces together (unsupervised) and only ask you to name the person once (supervised).

**Common Techniques**:
Self-training, Label Propagation, and Generative Adversarial Networks (GANs)
