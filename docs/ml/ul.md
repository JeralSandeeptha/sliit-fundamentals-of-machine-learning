# Unsupervised Learning

The model trains on `unlabeled` data.

It must find hidden patterns, structures, and groupings on its own without any human guidance.

<br/>

**Clustering**:
Groups data points based on similarities.
Example: Segmenting customers by purchasing habits.

**Dimensionality Reduction**:
Simplifies large datasets while retaining crucial details.
Example: Principal Component Analysis (PCA).

**Common Algorithms**:
K-Means Clustering, Hierarchical Clustering, and Apriori.
